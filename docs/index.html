Make one of your own

In Claude Code, install the plugin:

/plugin marketplace add diagrammo/skills
/plugin install diagrammo@diagrammo

Then ask for a codebase report in your repository. The report goes to docs/codebase-report/report.html.

Any other agent that reads SKILL.md folders: copy the skill's folder into that agent's skills directory.

The projects shown here did not make or review these reports. Each project's own documentation is the authority on how it works.
